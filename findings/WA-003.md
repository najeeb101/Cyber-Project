# WA-003 - Finding Record

**Status:** Verified (manual), remediation and retest pending  
**Title:** Unauthenticated directory listing exposes internal files at `/ftp`  
**Affected URL/component:** `http://127.0.0.1:3000/ftp` and `/ftp/<file>`  
**Technical owner:** Member 3  
**Risk reviewer:** Member 4

## Preconditions

None. No account or session is required.

## Discovery and reproduction

**Discovery method:** Manual testing based on application behavior and known Juice Shop design (not reported by ZAP in the quick scan).

1. Request `http://127.0.0.1:3000/ftp` with no credentials.
2. Note the directory listing returned.
3. Send `curl.exe -s -I http://127.0.0.1:3000/ftp/acquisitions.md` and confirm HTTP 200.

File contents were intentionally not copied into the evidence or report.

## Expected behavior

Internal, backup and credential-store files are not served by the public web server. Directory listing is disabled and access requires authentication and authorization.

## Observed behavior

The server returns an HTTP 200 directory listing with 11 entries, including `incident-support.kdbx` (a KeePass database), `package.json.bak`, `package-lock.json.bak`, `coupons_2013.md.bak`, `encrypt.pyc`, `suspicious_errors.yml`, `acquisitions.md`, `legal.md` and `announcement_encrypted.md`. Files are downloadable without authentication (HTTP 200 on `acquisitions.md`).

## Evidence

- `evidence/manual-tests/WA-003-ftp-exposure.txt`

## Analysis

- OWASP category: A02:2025 Security Misconfiguration; also related to A01:2025 Broken Access Control (OWASP Top 10, 2025)
- Confidentiality impact: High. Backup, dependency and credential-store files give an attacker internal information and material for offline attacks.
- Integrity impact: None directly.
- Availability impact: None.
- CVSS-informed severity: High (indicative CVSS v3.1 base ~7.5: AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:N/A:N). Team should confirm the vector and record it here.
- Confidence and limitations: High that the listing and download are exposed. The contents of the files were not analysed, so real-world impact of each file (for example, whether the `.kdbx` is crackable) is not claimed. This is a deliberately vulnerable training app with synthetic data.

## Remediation and retest

**Recommended remediation:** Remove the public `/ftp` route and its static file serving, or place it behind authentication and authorization. Disable directory listing, remove backup/config files from the web root, and keep credential stores out of any served path.  
**Retest result:** Pending.
